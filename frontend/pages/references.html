References and AI use

This page documents resources and prompts used during development.

Course materials

  • CIS 2336 Web Project specifications and Phase 2 front-end implementation instructions provided through Canvas.
  • ArtConnect Phase 1 Planning & Design document by Asaiah Oragbon.

Images and multimedia

All artwork and event graphics in this project are original SVG illustrations created specifically for this student project. No external stock images are used.

The homepage includes a JavaScript-powered interactive image gallery as the multimedia element.

External resources

  • MDN Web Docs concepts for semantic HTML, forms, DOM events, and accessibility.
  • GitHub documentation for repositories and GitHub Pages deployment.

AI prompts used

  1. “Review the ArtConnect Phase 2 requirements and build a complete responsive front-end with a homepage, gallery, events page, artist submission form, FAQ page, references page, shared CSS, and JavaScript.”
  2. “Use the blue color palette from my Phase 1 plan and keep navigation and styling consistent across every page.”
  3. “Add at least six artworks, four events, dynamic event details, artwork filtering, collapsible FAQs, client-side form validation, and an interactive image gallery.”
  4. “Organize the files in the required frontend, css, js, images, pages, backend, and README structure, and make it ready for GitHub Pages.”

AI disclosure

AI tools were used for guidance, brainstorming, coding support, feedback, and refinement. I reviewed the project structure, content, design choices, and functionality so the final submission reflects my understanding of the course requirements.
