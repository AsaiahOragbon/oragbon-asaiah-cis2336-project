# ArtConnect

ArtConnect is a front-end website made for my CIS 2336 project. It helps artists share their work and helps visitors find local art and events.

## What the Website Includes

- A homepage with featured artwork and events
- A gallery with six artworks
- Search and category filters
- An events page with four events and clickable details
- An artwork submission form with validation
- A FAQ page with expandable answers
- A references page with sources and AI prompts
- A responsive layout for phones and computers
