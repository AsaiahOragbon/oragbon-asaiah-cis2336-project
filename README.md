# ArtConnect

ArtConnect is my CIS 2336 web project. It gives artists a place to share their work and helps visitors find artwork and local art events.

## Front End

The front end includes a homepage, gallery, events page, artwork submission form, FAQ page, and references page. It uses HTML, CSS, and JavaScript.

## Back End

The backend uses Node.js and Express. It can:

- Serve the ArtConnect website
- Handle GET requests
- Handle POST requests from the artwork form
- Check submitted artwork data
- Store submissions in a JavaScript array while the server is running
- Return a success or error message
